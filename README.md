# EPAM Assignment 2 — Tree & Graph Problems

This repository contains two interactive Tree and Graph algorithm projects built using HTML, CSS, and JavaScript.

## Projects

### 1. Tree of Trusted Servers 🌳
Uses DFS to calculate the XOR value from the root server to every server and identifies trusted servers based on threshold K.

**Algorithm:** DFS + XOR

### 2. Emergency Route Validation 🚨
Uses BFS to calculate the shortest distance from City 1 and identifies cities reachable within D roads.

**Algorithm:** BFS

## Technologies

- HTML
- CSS
- JavaScript
- Vis.js

## How to Run

1. Clone the repository.
2. Open the project in VS Code.
3. Open the root `index.html` using Live Server.
4. Select a problem from the dashboard.
