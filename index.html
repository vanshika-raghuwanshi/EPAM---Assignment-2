ABOUT THE PROJECT

Algorithms With Real-World Context

This project contains two medium-level Data Structures and Algorithms problems. The first problem applies DFS and XOR on a tree, while the second applies BFS to find shortest paths in a graph. Both projects provide an interactive frontend so that the algorithm is easier to understand and visualize.
