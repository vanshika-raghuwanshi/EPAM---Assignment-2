HOW IT WORKS

Algorithm Overview

01

Build the Tree

The server connections are represented as an undirected tree using an adjacency list.

02

Traverse Using DFS

Starting from Server 1, DFS visits every server while maintaining the XOR value calculated along the path.

03

Check Trust

A server is trusted when its path XOR value is greater than or equal to K.

04

Count Results

Finally, all trusted servers are counted and displayed with their path XOR values.

PERFORMANCE

Algorithm Complexity

The tree is traversed exactly once, making the solution highly efficient even for large networks.

TIME O(N)
